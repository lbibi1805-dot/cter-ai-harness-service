# About This Guide

This User's Guide describes version 7.0 of the Integrated Development Environment (IDE) that's part of the QNX Momentics tool suite. The guide introduces you to the QNX Momentics IDE by explaining the QNX development environment and how to build, run, and debug your QNX Neutrino applications and systems.

This guide assumes the following:

- On your host, you've installed the QNX Software Development Platform (SDP), which includes the QNX Momentics tool suite. QNX Momentics is a complete QNX Neutrino development environment.
- You're familiar with the [_System Architecture_](https://www.qnx.com/developers/docs/7.0.0/com.qnx.doc.neutrino.sys_arch/topic/about.html) guide of QNX Neutrino.
- You can write code in C or C++.
